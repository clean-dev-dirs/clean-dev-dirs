# clean-dev-dirs {{VERSION}}

## Install

With Cargo:

```bash
cargo install clean-dev-dirs
```

With Homebrew:

```bash
brew install clean-dev-dirs/clean-dev-dirs/clean-dev-dirs
```

With a binary: download the archive for your system from the assets below. Extract it, and move `clean-dev-dirs` to a directory in your `PATH`.

## Binaries

| Archive | System |
|---------|--------|
| `clean-dev-dirs-{{VERSION}}-linux-x86_64.tar.gz` | Linux, x86_64 |
| `clean-dev-dirs-{{VERSION}}-macos-x86_64.tar.gz` | macOS, Intel |
| `clean-dev-dirs-{{VERSION}}-macos-arm64.tar.gz` | macOS, Apple Silicon |

The `*.bottle.tar.gz` files are the Homebrew bottles. The file `clean-dev-dirs-{{VERSION}}.tar.gz` contains the source code.
